# PRD: Локальная транскрибация загруженных файлов встречи через Whisper

**Дата**: 2026-09-26
**Статус**: Draft

## Цель

Пользователь загружает mp4/mp3 файл во встречу и автоматически получает его текстовую расшифровку (транскрипцию), выполненную локальной моделью Whisper, не покидая приложение и не используя внешние сервисы.

## Пользовательские сценарии

- Пользователь загружает mp4/mp3 файл во встречу -> транскрибация запускается автоматически, без дополнительных действий пользователя.
- Пользователь открывает встречу с загруженным файлом, транскрибация ещё не завершена -> видит статус "в очереди" или "в процессе" рядом с файлом.
- Транскрибация файла завершилась успешно -> пользователь видит статус "готово" и текст транскрипции, доступный для просмотра.
- Транскрибация файла завершилась с ошибкой -> пользователь видит статус "ошибка".
- Пользователь загружает файл в формате, отличном от mp4/mp3 -> транскрибация для него не запускается.

## В скоупе

- Автоматический запуск транскрибации сразу после успешной загрузки файла формата mp4 или mp3 во встречу.
- Использование локальной модели Whisper (размер модели — low) без обращения к внешним API.
- Автоопределение языка распознаваемой речи средствами Whisper.
- Хранение статуса транскрибации файла: в очереди / в процессе / готово / ошибка.
- Отображение статуса транскрибации в интерфейсе рядом с соответствующим файлом встречи.
- Хранение и отображение текста готовой транскрипции для просмотра пользователем.
- Обработка каждого загруженного mp4/mp3 файла как отдельной единицы транскрибации.

## Не в скоупе

- Транскрибация файлов других форматов (например, wav, m4a, avi).
- Ручной запуск/перезапуск транскрибации пользователем.
- Редактирование текста транскрипции пользователем.
- Разбивка транскрипции по спикерам (диаризация).
- Таймкоды и синхронизация текста с видео/аудио плеером.
- Скачивание транскрипции отдельным файлом (например, .txt/.srt).
- Уведомления (push/email) о завершении транскрибации.
- Выбор пользователем модели Whisper или языка распознавания.
- Транскрибация файлов, загруженных до появления этой фичи (ретроактивная обработка).

## Технические ограничения

- Транскрибация выполняется локальной моделью Whisper (low) — качество и скорость ограничены размером модели.
- Обработка выполняется на сервере приложения; производительность зависит от доступных вычислительных ресурсов и может создавать очередь при одновременной загрузке нескольких файлов.
- Длительность обработки зависит от длины аудио/видео файла и может занимать значительное время для больших файлов.

## Критерии готовности

- [ ] После загрузки mp4 или mp3 файла во встречу транскрибация запускается автоматически без действий пользователя.
- [ ] Статус транскрибации файла отображается в интерфейсе встречи и принимает одно из значений: в очереди, в процессе, готово, ошибка.
- [ ] Статус в интерфейсе обновляется по мере изменения реального статуса обработки без необходимости пользователю самому обновлять страницу.
- [ ] При статусе "готово" пользователю доступен для просмотра текст транскрипции файла.
- [ ] При статусе "ошибка" пользователю показывается соответствующее сообщение, текст транскрипции не отображается.
- [ ] Для файлов форматов, отличных от mp4/mp3, транскрибация не запускается и статус транскрибации не отображается.
- [ ] Каждый загруженный mp4/mp3 файл встречи получает собственный независимый статус и текст транскрипции.
