# PRD: Выжимка встречи (summary, action items, решения) через OpenRouter

**Дата**: 2026-09-30
**Статус**: Draft (обновлено 2026-09-30: автозапуск агентом вместо ручной кнопки)

## Цель

Пользователь по готовым транскрипциям встречи получает структурированную выжимку — краткое summary, список action items с ответственными и список принятых решений, — подготовленную автоматически агентом на базе LLM (OpenRouter, tool calling), чтобы не перечитывать расшифровку целиком.

## Пользовательские сценарии

- Пользователь загружает аудио/видео (mp3/mp4) -> файл транскрибируется, а когда у встречи не осталось файлов в очереди/в процессе транскрибации, агент сам запускается и дополняет встречу summary, action items и решениями; пользователь видит статус «ждём транскрибацию» → «анализируем встречу» → готовую выжимку без каких-либо действий.
- Во встрече обсуждалась задача с названным исполнителем -> в action item указан ответственный в том виде, как он был назван во встрече.
- Во встрече обсуждалась задача без исполнителя -> action item отображается без ответственного.
- Во встрече не было action items или решений -> соответствующий раздел отображается с пометкой «нет».
- Пользователь загружает в встречу ещё один файл -> после его транскрибации агент пересобирает выжимку по всем готовым транскрипциям, новая выжимка заменяет предыдущую.
- Агент завершился с ошибкой -> в блоке выжимки отображается ошибка с кнопкой «Повторить».
- Пользователь открывает встречу, у которой нет ни одной готовой транскрипции (и транскрибация не идёт) -> блок выжимки не отображается.
- Пользователь повторно открывает встречу после завершения генерации -> видит сохранённую выжимку без повторной генерации.

## В скоупе

- Одна выжимка на встречу, построенная по всем транскрипциям файлов встречи со статусом «готово».
- Автоматический запуск агента после завершения транскрибации (событие бэкенда); запуск только когда у встречи нет файлов в статусах «в очереди»/«в процессе» и есть хотя бы одна готовая транскрипция. Если генерация уже идёт, а появилась новая транскрипция — после неё выполняется повторный прогон.
- Агент с вызовом инструментов (tool calling) через OpenRouter (модуль `open-router` в api): инструменты записи summary, добавления action item, добавления решения и завершения работы; результат сохраняется в БД целиком только после завершения.
- Кнопка «Повторить» в блоке ошибки (ручной запуск существующим `POST /meetings/:id/summary`).
- Состав выжимки:
  - summary — краткий связный текст о содержании встречи;
  - action items — список задач; у каждой: описание и ответственный (свободный текст, как прозвучал во встрече; пусто, если не назван);
  - принятые решения — отдельный список.
- Язык выжимки совпадает с языком транскрипции.
- Статус генерации выжимки: в процессе / готово / ошибка.
- Сохранение выжимки и её статуса в БД; повторная генерация полностью заменяет предыдущую выжимку.
- Отображение выжимки на странице встречи после завершения обработки; отображение статуса, пока обработка идёт.
- Запуск генерации и просмотр выжимки доступны только пользователям, имеющим доступ к встрече.

## Не в скоупе

- Ручная кнопка генерации/перегенерации в шапке блока выжимки и поясняющая подпись под ней (удалены).
- Генерация через Claude Agent SDK / Anthropic API напрямую (агент работает через OpenRouter).
- Отдельная выжимка для каждого файла встречи.
- Сопоставление ответственного с участниками встречи или пользователями системы.
- Сроки (дедлайны) и приоритеты у action items.
- Редактирование выжимки, отметка action items выполненными, трекинг задач.
- Выбор пользователем LLM-модели, языка или формата выжимки.
- Экспорт выжимки (файл, email, интеграции с таск-трекерами).
- Уведомления о завершении генерации (пользователь видит статус на странице).
- История версий выжимки.

## Технические ограничения

- Генерация зависит от внешнего сервиса OpenRouter: требуется `OPENROUTER_API_KEY`, возможны сетевые ошибки, таймауты и лимиты запросов (бесплатные `:free`-модели — 20 запросов/мин и 50 запросов/день).
- Текст транскрипций передаётся во внешний сервис (OpenRouter и провайдер модели) — в отличие от транскрибации, обработка не локальная.
- Суммарный объём транскрипций длинной встречи может превышать контекстное окно выбранной модели.
- Ответ LLM недетерминирован и может не соответствовать ожидаемой структуре — некорректный ответ должен приводить к статусу «ошибка», а не к сохранению битых данных.
- Качество выделения ответственных ограничено качеством транскрипции Whisper (low) и отсутствием диаризации: имена могут распознаваться с ошибками.

## Критерии готовности

- [ ] Выжимка создаётся автоматически после завершения транскрибации всех файлов встречи, без действий пользователя; ручной кнопки генерации в шапке блока и подписи под ней нет.
- [ ] При нескольких файлах агент стартует только после завершения всех транскрибаций (статусы «готово» или «ошибка»); упавшая транскрибация не блокирует выжимку по остальным.
- [ ] Выжимка строится по всем готовым транскрипциям встречи; транскрипции в статусах «в очереди», «в процессе», «ошибка» не учитываются.
- [ ] Выжимку, action items и решения записывает агент через вызовы инструментов (OpenRouter).
- [ ] После успешной генерации на странице встречи отображаются три раздела: summary, action items, принятые решения.
- [ ] У каждого action item отображается описание; ответственный отображается, если он был назван во встрече, иначе поле пустое.
- [ ] Язык выжимки совпадает с языком транскрипции (проверено на русской и английской записи).
- [ ] Выжимка и её статус сохраняются в БД и отображаются после перезагрузки страницы без повторной генерации.
- [ ] Пока генерация идёт, во встрече отображается статус «в процессе»; статус обновляется без ручной перезагрузки страницы.
- [ ] При ошибке OpenRouter или некорректном ответе модели статус становится «ошибка», частичные данные не сохраняются, генерацию можно запустить повторно кнопкой «Повторить».
- [ ] Пока транскрибация идёт, блок выжимки показывает «ждём завершения транскрибации»; при статусе «ошибка» — кнопка «Повторить».
- [ ] Новая транскрипция пересобирает выжимку по всем готовым транскрипциям и заменяет предыдущую целиком.
- [ ] Повторный ручной запуск для той же встречи во время генерации через API отклоняется (409).
- [ ] Пользователь без доступа к встрече не может ни запустить генерацию, ни получить выжимку (ответ API 403/404).
